# 3D-modeling

## Описание
Лендинг компании, предоставляющей услуги по 3D моделированию интерьера.\
В проекте используется нативный JavaScript и сборщик Vite.

## Установка
1. Клонируйте репозиторий:
```bash
git clone https://github.com/ttseva/3D-modeling.git
cd 3D-modeling
```

2. Установите зависимости:
```bash
npm install
```

3. Запустите приложение локально:
```bash
npm start
```

Оно будет доступно по адрес `http://localhost:3000/`
